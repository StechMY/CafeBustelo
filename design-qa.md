4. **Image quality and asset fidelity:** generated portrait/wide atmosphere, cabinet, embossed gold egg, progressive crack states, shattered shell, hammer, glow, and metallic button are installed as real optimized WebP assets. The supplied logo remains its original vector. Standard UI icons use Phosphor Thin; the activity navigation icon is the actual egg raster. Transparency and crops were inspected. 5. **Copy and content:** invitation copy intentionally changes the selected mock's registration condition to the user's revised first-successful-purchase condition. Registration alone does not earn a chance. Confirmation states one chance is consumed for ordinary users; the agent label and confirmation omit infinity/unlimited wording. Agent counters display a random 1–10 while actual agent draws remain available. Reward copy distinguishes recharge-wallet credits and single-use, non-stacking purchase discounts. App text contains no design/build instructions. Chinese was visually reviewed; other translated locale keys are present, but not every locale was visually exercised at every breakpoint.
